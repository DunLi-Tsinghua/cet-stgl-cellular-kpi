\section{CET-STGL Representation and Evaluated Instantiation}
\label{sec:methodology}

\subsection{Overview}
CET-STGL is a causal-inspired event-token spatio-temporal representation framework for structured cellular operations data. Heterogeneous signals are first aligned to the same cell-time-horizon index and then passed to forecasting, classification or prioritization heads. The evaluated representation is
\begin{equation}
    \mathbf{z}_{c,t,h}=
    [\boldsymbol{\phi}^{\mathrm{kpi}}_{c,t},
    \boldsymbol{\phi}^{\mathrm{event}}_{c,t},
    \boldsymbol{\phi}^{\mathrm{pos}}_{c,t},
    \boldsymbol{\phi}^{\mathrm{prior}}_{c,t,h},
    \boldsymbol{\phi}^{\mathrm{graph}}_{c,t}],
\end{equation}
where the five blocks correspond to KPI patches, alarm events, cell/time context, event influence priors and inferred cross-cell context. We evaluate a lightweight sklearn-based instantiation to examine the representation under a leakage-controlled protocol.

The design follows three reliability-oriented constraints. KPI histories are summarized as local level and slope patches, sparse alarms are encoded by counts, decayed intensity and train-only association priors, and cross-cell context is inferred from training-period operational correlations when topology is unavailable. Compared with simple feature concatenation, CET-STGL imposes an explicit prediction-time constraint on each $(c,t,h)$ target and uses one admissible cell-time representation across all three evaluation tasks.

For any prediction target at $(c,t+h)$, the evaluated CET-STGL feature vector is a function only of the lookback window $\mathcal{W}_{c,t}$, identifiers and time features available at $t$, and statistics fitted on the chronological training partition. No validation/test labels, post-$t$ observations or future event information are used in feature construction. KPI patch features, alarm counts and decayed intensities are computed within $\mathcal{W}_{c,t}$. Degradation thresholds, feature scalers, event lifts and cross-cell graph statistics are estimated from the training partition only, and windows crossing the long time discontinuity are excluded before model fitting. This admissibility statement concerns leakage-controlled representation construction, not causal identification or performance optimality.

\subsection{KPI, Event and Positional Features}
For each KPI $m$ in a lookback window, the sequence $x^{(m)}_{c,t-L+1:t}$ is divided into short patches and summarized by local statistics:
\begin{equation}
    \phi^{\mathrm{kpi}}_{c,t,p,m}=
    [\mathrm{mean},\mathrm{slope}]_{c,t,p,m}.
\end{equation}
The patch summaries preserve local level and slope while reducing raw sequence length. Patch-based time-series modeling provides a direct precedent for representing long temporal windows through compact local segments \cite{nie2023patchtst}.

Alarm/fault observations are represented as sparse event features. For alarm type $a$, we compute rolling counts and a decayed event intensity
\begin{equation}
    \lambda_a(c,t)=\sum_{\tau \leq t} \mathbf{1}[a_{c,\tau}>0]\exp\left(-\frac{t-\tau}{\eta}\right),
\end{equation}
where $\eta$ is a fixed decay scale. The term Hawkes-inspired refers to the recency-weighted form, in which recent events contribute more strongly than older events \cite{hawkes1971spectra,mei2017neuralhawkes}. In the evaluated implementation, the decayed intensity is a fixed event feature, which is appropriate for the observed sparsity: only 11 of 137 alarm/fault columns are active and only 1.62\% of rows contain an active alarm.

Cell identity and time context are encoded through cell-code features and cyclical time features such as hour-of-day and day-of-week. These positional features capture persistent cell offsets and periodic operational behavior. All transformations are fitted within the chronological training protocol, and windows crossing the detected long time gap are excluded.

\subsection{Event Influence Prior and Cross-Cell Context}
For each alarm type and horizon, the evaluated instantiation estimates a train-only lagged lift:
\begin{equation}
    \mathrm{lift}_h(a)=
    \log\frac{P_{\mathrm{train}}(y_{c,t+h}=1 \mid a \in \mathcal{W}_{c,t})+\epsilon}
    {P_{\mathrm{train}}(y_{c,t+h}=1)+\epsilon},
\end{equation}
where $P_{\mathrm{train}}$ denotes a training-set probability and $\epsilon$ is a smoothing constant. The lift is combined with recent intensity to form $\boldsymbol{\phi}^{\mathrm{prior}}_{c,t,h}$. This prior encodes training-period association between alarms and weak degradation; it is causal-inspired but does not estimate a causal effect.

The evaluated panel does not include verified physical topology. We infer a cross-cell context graph $G_{\mathrm{cell}}=(\mathcal{C},E)$ from training-period KPI correlations. For cell $c$, neighbor context is summarized as
\begin{equation}
    \boldsymbol{\phi}^{\mathrm{graph}}_{c,t}
    =\frac{1}{|\mathcal{N}(c)|}\sum_{c'\in\mathcal{N}(c)}\mathbf{u}_{c',t},
\end{equation}
where $\mathcal{N}(c)$ is the inferred neighbor set and $\mathbf{u}_{c',t}$ denotes selected KPI context for cell $c'$. The inferred graph is a statistical context graph, not a physical deployment graph. Training-derived cross-cell context follows the broader idea of using graph structure or adaptive spatial dependencies for time-series forecasting, while remaining explicitly statistical in the present dataset \cite{li2018dcrnn,wu2019graphwavenet}.

\subsection{Evaluated Prediction Heads}
The evaluated heads are
\begin{equation}
    \hat{\mathbf{x}}_{c,t+h}=f_h^{\mathrm{reg}}(\mathbf{z}_{c,t,h}),\qquad
    \hat{p}_{c,t+h}=g_h^{\mathrm{cls}}(\mathbf{z}_{c,t,h}),\qquad
    \widehat{\pi}_{c,t,h}=\mathrm{rank}_{a\in\mathcal{A}_{c,t}}\,s_h(a,c,t).
\end{equation}
The implementation uses Ridge regression for multi-output KPI forecasting, a linear logistic classifier trained using stochastic gradient descent for weak degradation classification, and event-lift/intensity scoring for weak alarm-candidate prioritization. End-to-end neural spatio-temporal graph evaluation remains future work under the same leakage-controlled protocol.
